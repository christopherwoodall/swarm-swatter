# SWARM SWATTER — TRACE-3D

91 days of swarm-forensics event data (2026-04-19 → 2026-07-18; 36 nodes, 86 edges, 96,353 annotated events) rendered as thirteen interactive 3D visualizations with sonification. All data is embedded in each single self-contained HTML file — no network calls, works offline.

## Play it

**`index.html` — SWARM SWATTER.** The playable one: two thumbs drive the red/blue sabers, slash blocks as they reach you, follow the arrows for PERFECT ×1.5. Misses break your combo. Or hit 🎮 again for the cinematic watch mode.

## The rest

particles · spatial · voxels · constellation · city · saber · mycelium · storm · fireworks · heart · pianola · cathedral · anthill — each a different lens on the same dataset.

Built from `trace-build/` (Three.js r149, Web Audio sonification). Mobile-first: touch controls, readable labels, speed selection.
