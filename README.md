# SWARM SWATTER

91 days of swarm-forensics event data (2026-04-19 → 2026-07-18; 36 nodes, 86 edges, 96,353 annotated events) turned into a playable rhythm slasher. All data is embedded in one self-contained HTML file — no network calls, works offline, mobile-first.

**Play:** https://christopherwoodall.github.io/swarm-swatter/

Two thumbs drive the red/blue sabers — slash blocks as they reach you, follow the arrows for PERFECT ×1.5. Misses break your combo. Tap 🎮 for the cinematic watch mode.

Built from `trace-build/scene-saber.js` (Three.js r149, Web Audio sonification at 92 BPM).
